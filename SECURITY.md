# Security Policy

If you find a vulnerability anywhere in alumina-proxy, such as the source or scripts, then please let the project maintainer @acje know ASAP and I will fix it as a critical priority.

[Open a private security advisory](https://github.com/acje/alumina-proxy/security/advisories/new) to report it confidentially to the project maintainer. Do not report vulnerabilities in public issues or pull requests.

I welcome analysis and proof of concepts generated by AI, but for the advisory to be accepted it must have had human oversight and checking.

Failure to follow this policy may result in the advisory being closed and/or no credits given to the reporter.
